# 🧰 TECH STACK DEFINITION

## 1. Core Framework
* **Framework:** Next.js 14+ (App Router).
* **Language:** TypeScript (Strict Mode).
* **Package Manager:** npm or pnpm.

## 2. Frontend & Styling
* **Styling Engine:** Tailwind CSS.
* **Component Library:** Shadcn UI (Radix Primitives).
* **Icons:** Lucide React.
* **Fonts:** Inter (via `next/font`).
* **Animations:** Framer Motion (for "Traffic Light" transitions).

## 3. Backend & Data
* **BaaS (Backend as a Service):** Supabase.
* **Database:** PostgreSQL (managed by Supabase).
* **Auth:** Supabase Auth (Google OAuth Provider).
* **State Management:** React Query (TanStack Query) - *Preferred for fetching data.*

## 4. Development Tools
* **Linting:** ESLint (Next.js config).
* **Formatting:** Prettier.
* **Version Control:** Git.
* **Code Review:** CodeRabbit (AI).

## 5. Deployment
* **Host:** Vercel (Hobby Plan).
* **CI/CD:** Vercel Automatic Deployments (Git Integration).
